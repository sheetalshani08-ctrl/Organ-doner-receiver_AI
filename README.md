# 🫀 Organ Donor & Receiver Matching System

A simple **Organ Donor & Receiver Matching Web Application** built using Python, Gradio, SQLite, Pandas, and Matplotlib.

## 🚀 Features

* 🧑‍⚕️ Register organ donors
* 🏥 Register organ recipients
* 🧩 Match donors and recipients based on:

  * Blood group
  * Organ type
  * Medical urgency
  * Location
  * Age
* 📊 Generate compatibility scores and graphs
* 💾 Store data using SQLite
* 🌐 Interactive Gradio web interface

## 🛠️ Technologies

* Python
* Gradio
* SQLite
* Pandas
* Matplotlib
* Google Colab

## ▶️ Run the Project

Install dependencies:

```bash
pip install gradio pandas matplotlib
```

> `sqlite3` does not need to be installed because it is included with Python.

Open the notebook in **Google Colab** and run the cells. A Gradio web link will be generated.

## ⚠️ Note

This is an **educational prototype** and not a medically validated organ allocation system. Do not use real patient or donor information.
